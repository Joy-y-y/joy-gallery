# Joy-Y

Joy 的 AltStore / SideStore 静态软件源。

## 导入

在 AltStore / SideStore 的「源（Sources）」中添加以下地址：

```
https://raw.githubusercontent.com/Joy-y-y/joy-gallery/main/all-apps.json
```

## 说明

- 本源共收录 **51** 个应用，应用元数据、图标、截图与 IPA 下载链接均复用自公开开源项目（镜像自 [AltGallery](https://github.com/bebound/AltGallery)）。
- 图标、截图与 IPA 本体仍托管在原项目的 GitHub Releases / 仓库地址，本仓库只维护源清单 JSON。
- 如需替换为自有应用、图标、截图与 IPA 链接，修改 `all-apps.json` 中对应条目即可。

## 文件

- `all-apps.json` — AltStore 格式软件源清单
